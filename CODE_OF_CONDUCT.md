# Community Code of Conduct

Bitcase welcomes people of different backgrounds and experience levels.

Participants must:

- discuss ideas and code without personal attacks;
- give specific, evidence-based technical feedback;
- respect privacy and confidential project information;
- avoid harassment, discrimination, threats, and unwanted sexual attention;
- avoid publishing credentials or another person's identifying information;
- disclose conflicts of interest when recommending a Skill or vendor; and
- follow maintainer decisions about security disclosure and moderation.

Unacceptable behavior may result in content removal, temporary restriction, or
permanent removal from project spaces.

Report conduct concerns privately to the maintainers through the repository's
moderation or security contact. Do not create a public issue containing
sensitive personal information.

Maintainers should explain enforcement decisions when doing so would not expose
private information or increase harm.
